# 🔥 Streak OS — نسخه ۱۱

برنامه‌ی پیگیری عادت‌ها و فعالیت‌های روزانه — کاملاً فارسی، تک‌فایل و آفلاین.

## ✨ امکانات

- 🗣️ **رابط کاربری کاملاً فارسی** (RTL) — بدون هیچ زبان اضافه
- 🗓️ **دو تقویم مستقل**: شمسی (پیش‌فرض) و میلادی — قابل تغییر از تنظیمات ← زبان و تقویم
- ⚡ **حالت آسان**: با یک کلیک فقط فعالیت‌ها و ثبت سریع هدف را می‌بینید
- 📋 **دراپ‌داون دسته‌بندی** + 📂 **تنظیمات تاشو** + 🖱️ **اسکرول‌بار هماهنگ با تم** + 🔥 favicon اختصاصی
- 📊 تحلیل‌ها: ۵ شاخص کلیدی، خط زمان، نقشه‌ی حرارتی، نمودارها
- 💾 **دیتابیس دلتا (جدید در v11)** — ذخیره‌سازی فقط تغییرات، نه بازنویسی کل دیتابیس
- ☁️ **سینک دلتای گیت‌هاب (جدید در v11)** — فایل‌های تغییرات append-only + snapshot خودکار + هرس خودکار
- 🧱 **خروجی SQLite واقعی (جدید در v11)** — فایل `.sqlite` با اسکیمای رابطه‌ای استاندارد
- 🛡 رمزنگاری AES-GCM (PBKDF2 / 310k) — داده‌ها روی دستگاه خودتان می‌مانند

## 🚀 اجرا

فایل [`index.html`](index.html) را دانلود کنید و در مرورگر باز کنید. همه‌چیز آفلاین کار می‌کند.

یا اگر GitHub Pages فعال باشد، مستقیم از آدرس صفحه‌ی سایت استفاده کنید.

## 🗄 دیتابیس نسخه ۱۱ (Delta Core)

از نسخه ۱۱، مدل داده‌ی برنامه یک دیتابیس رابطه‌ای دلتاست:

- **ذخیره‌سازی دلتا**: هر تغییر فقط رکوردهای تغییرکرده را می‌نویسد و عملیات‌ها را در ژورنال (`change_log`) ثبت می‌کند — دیگر هیچ‌گاه کل دیتابیس بازنویسی نمی‌شود.
- **سینک دلتا**: در مخزن گیت‌هاب شما به‌جای یک فایل JSON بزرگ، یک مخزن دلتا ساخته می‌شود (`manifest.json` + فایل‌های تغییرات الحاقی + snapshot دوره‌ای). هر سینک = یک کامیت اتمی کوچک؛ رشد تاریخچه‌ی گیت متناسب با «تعداد تغییرات» است نه «حجم دیتابیس».
- **مسیر PostgreSQL**: اسکمای مرجع در [`db/schema.sql`](db/schema.sql) (SQLite) و [`db/schema.postgres.sql`](db/schema.postgres.sql) آماده است و مدل عملیات برای مهاجرت آینده به سرور طراحی شده — توضیح کامل در [`db/ARCHITECTURE.md`](db/ARCHITECTURE.md).
- **مهاجرت خودکار**: دیتابیس محلی نسخه‌های قبلی و فایل ابری قدیمی، در اولین استفاده به‌صورت خودکار و بدون افت داده به مدل جدید منتقل می‌شوند (نسخه‌ی پشتیبان هم گرفته می‌شود).
