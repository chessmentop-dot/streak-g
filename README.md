# 🔥 Streak OS — نسخه ۱۰.۲

برنامه‌ی پیگیری عادت‌ها و فعالیت‌های روزانه — کاملاً فارسی، تک‌فایل و آفلاین.

## ✨ امکانات

- 🗣️ **رابط کاربری کاملاً فارسی** (RTL) — بدون هیچ زبان اضافه
- 🗓️ **دو تقویم مستقل**: شمسی (پیش‌فرض) و میلادی — قابل تغییر از تنظیمات ← زبان و تقویم، با نمایش تاریخ و ماه‌ها به فارسی در هر دو حالت
- ⚡ **حالت آسان**: با یک کلیک فقط فعالیت‌ها و ثبت سریع هدف را می‌بینید — با ۹ گزینه‌ی قابل تنظیم و امکان ساخت پریست‌های شخصی
- 📋 **دراپ‌داون دسته‌بندی**: هنگام انتخاب دسته، لیست دسته‌های موجود با شمارش فعالیت‌ها نمایش داده می‌شود + ساخت دسته‌ی جدید
- 📂 **تنظیمات تاشو**: همه‌ی بخش‌های تنظیمات به‌صورت پیش‌فرض بسته با فلش باز/بسته می‌شوند
- 🖱️ **اسکرول‌بار هماهنگ با تم**: رنگ اسکرول‌بار در هر ۱۷ پوسته به‌صورت خودکار با تم تطبیق می‌کند
- 🔥 **favicon اختصاصی** (شعله روی گرادیان)
- 📊 تحلیل‌ها: ۵ شاخص کلیدی، خط زمان، نقشه‌ی حرارتی، نمودارها
- 🔄 سینک با گیت‌هاب، بکاپ و بازیابی داده
- 💾 ذخیره‌سازی محلی (IndexedDB) — داده‌ها روی دستگاه خودتان می‌ماند

## 🚀 اجرا

فایل [`index.html`](index.html) را دانلود کنید و در مرورگر باز کنید. همه‌چیز آفلاین کار می‌کند.

یا اگر GitHub Pages فعال باشد، مستقیم از آدرس صفحه‌ی سایت استفاده کنید.
